# 《腾云香局》游戏设计文档（GDD v1）

> 版本：v1.0 草案 ｜ 状态：大纲已定稿，数值与部门细节为占位，边做边补
> 一句话定位：**一款以"仙朝衙门打工人"为皮的讽刺系放置挂机游戏，用修仙数值讲职场人生。**

---

## 1. 游戏概述与体验目标

| 项目 | 内容 |
|---|---|
| 类型 | 放置挂机（Idle）+ 轻叙事 + 排行榜社交 |
| 平台 | PC 浏览器优先，手机浏览器自适应；不做原生 App |
| 目标玩家 | 第一期为几位朋友的私享局；架构预留公开网游化 |
| 单局周期 | 主线约 3~4 周（每天主动操作约 15 分钟 + 收菜 2~3 次），通关后内容可无限续挂 |
| 核心体验 | 前期热血升级 → 中期起疑 → 后期醒悟 → 结局释然；讽刺但不虚无 |
| 情感基调 | 国潮幽默讽刺喜剧，重大时刻用水墨点缀制造反差 |

### 三条设计铁律

1. **存档永不作废**：游戏里没有真正的"结局"，只有"转折"；任何选择之后都能继续挂机。
2. **三类玩家都不被抛弃**：肝帝（进度流）、挂机党（时间流）、收集党（集藏流）各有对应的奖励通道。
3. **隐射不留指纹**：全程无现代公司词汇；所有真人特征抽象为原型人设；真实公司名称与人员信息绝不进入任何游戏文件。

## 2. 世界观与隐射对照

### 2.1 总设定

**腾云香局** —— 仙朝官办的灵草种植与仙香制炼衙署。核心产业链：
**种灵叶 → 卷仙香 → 行销四海**。香局命脉在海外——仙香大多远销重洋之外的番邦异域，海路即财路。
"腾云"一语三关：香烟腾云、平步青云、嘴上大道可期。

所有修仙者的终极梦想不是长生，而是**考入仙朝天庭的编制（仙籍）**。
而真相是：**仙籍对编外杂役从不开放——从未有一人做到**（见 §6 主线设计）。

### 2.2 隐射对照表（文案弹药库）

| 现实概念 | 游戏表达 |
|---|---|
| 公司 | 腾云香局（仙朝官办衙署） |
| 编制/编外 | 仙籍 / 编外杂役（同工不同酬：仙籍俸禄约为杂役 3 倍，另有"洞府补贴"一项，几乎抵得上杂役一月俸禄；考成要求还不同） |
| 领导层 | 堂上诸公（局座/丞局/同知）——不可见、不开玩笑，只以"天象"形式影响全局 |
| KPI 考核 | 考成法（每旬结算） |
| 画饼 | 上官的"大道期许" |
| 打卡 | 点卯 |
| 开会 | 升堂议事（产出暂停，上官好感+） |
| 加班 | 燃灯值守（产出×2，次日心力上限减半） |
| 周报 | 功过册 |
| 离职/跳槽 | 辞官 / 改换门庭 |
| 内卷 | 道心竞争 |

## 3. 部门职业体系

部门 = 职业（Class）。开局选择部门决定玩法流派；通关/跳槽后可换部门重开。
玩家自由选择出身部门（不设默认推荐），每个部门配套一整套专属随机事件，确保每位玩家的衙门人生体验不同。

**机会均等铁律（2026-08 决议）**：部门决定"用什么姿势参与"，绝不决定"能不能参与"。监正争夺战等大事件对全体玩家开放，任何部门的玩家都有同等机会参加；部门专属内容仅限功法/被动修正/风味事件，不得做成独占的进度或奖励通道。

**扩展玩法全员开放细则（2026-08 决议）**：由部门定位引出的扩展玩法一律是全服系统，不设部门门禁——远航出差任何部门的玩家都能出海，考成裁定全员参加，审计合规内容全员可接触；对应部门只享受被动加成而非独占资格（如广闻司玩家远航收益更高，但不能垄断远航；吏房玩家考成评分更稳，但不能豁免他人）。刑名房"一房两堂"选边是职业内部的流派分叉，两堂对应的玩法内容（合规减免/审计记功）对所有玩家开放，刑名房玩家在其中有先天加成。

### 3.1 部门换皮总表

| 游戏部门 | 原型职能 | 定位关键词 |
|---|---|---|
| 签押房 | 综合事务 | 均衡万金油、同僚好感、被动加班 |
| 筹云司 | 战略发展 | 高能力强压力、监正之位虚悬（争位剧情钩子） |
| 广闻司 | 市场营销 | 绩效流：香局主业部门、出海次数最多；出海远航（出差）=长期离线特殊模式 |
| 漕运司 | 供应链 | 贸易调度流：低买高卖、路线规划；NPC 双原型（豪爽老漕头/精明仓吏） |
| 制香坊 | 生产运营 | 生产链管理流：灵叶→仙香加工倍率；设定上"全衙门最神秘的部门" |
| 户房 | 财务 | 经济碾压流：俸禄最高、心力消耗巨大、大限风暴、NPC 高流失 |
| 吏房 | 人力资源 | 冷面判官：考成裁定者，好感难刷收益大 |
| 机巧阁 | 信息数字化 | 装备科技流：法宝/机关最强，前期弱后期猛；主线剧情主舞台 |
| 刑名房 | 合规风控 | 独家机制「一房两堂」：入部门须选边（合规堂/审计堂），两套技能树 |
| 察案院 | 监察 | 整活流：巡查全是表演（预告式巡查），教玩家做表面功夫 |

### 3.2 部门上线计划（2026-08 更新：首发即十房）

- **v1 首发 10 部门**：十家的部门数据与专属功法全部上线，玩家开局十选一。
- **独家机制后置**：筹云司（监正争夺战，M5 主线事件）、广闻司（远航四海离线模式）、吏房（考成裁定）、刑名房（一房两堂双技能树）的独家机制随各自依赖的系统就绪后逐个点亮；按机会均等铁律，监正争夺战等大事件对全体玩家开放，非筹云司玩家同样可参与。

### 3.3 办差力 · 法器 · 案牍山（战力系统，2026-08 决议）

修仙挂机品类的留存核心是"战力成长→推图→掉落→更强"的飞轮。本游戏将其完整换皮：

| 修仙挂机 | 腾云香局包装 |
|---|---|
| 装备 | 法器·办公灵具（掌中器/护身/养魂/奇巧四槽） |
| 战力 | 办差力（职级×功法×法器的综合值） |
| 推图打怪 | 案牍山·差事（办差力卡档位，全自动办结） |
| 日常副本 | 每日案牍牌（日常任务：自动记进度、一键领赏） |
| 材料锻造 | 差事掉落材料 → 机巧阁锻造/强化 |

**功法双槽制（M3 落地）**：
- 通用槽：《摸鱼心法》，产出+15%/级，人人可研。
- 部门专属槽：选定部门后解锁一门，效果按部门定位差异化（数值待调）：
  - 签押房《乡音诀》：摸鱼冷却减半——同僚打掩护，摸鱼更从容
  - 户房《算盘经》：俸禄+25%，心力消耗+30%——钱多命短
  - 制香坊《调香手札》：收菜所得+20%——手艺人的收成
  - 漕运司《漕路要略》：离线收益倍率+0.2——船在走，钱在流
  - 机巧阁《格物篇》：研习费×0.8——技术流学习成本天生低
  - 察案院《表面功》：摸鱼值获取×2——表面功夫也是功夫

**办差力** = 职级 + 功法双槽 + 法器四维合成的综合数值，是差事档位的唯一门禁。

**案牍山（M4 落地）**：差事=怪，按档位刷新；办差力达标自动办结，产出灵石+材料（灵石之外的第二条产出管道）。肝帝冲法器推差事滚雪球，挂机党只挂工位不受影响——第一原则不破。

**摸鱼原则合规（三条铁律）**：差事战斗全自动、日常任务自动记进度只需一键领赏、法器强化一键完成。战力系统的一切操作频次不得超过每日数次。


### 3.4 部门差异化五维度模板（逐部门填充，占位）

每个部门从以下 5 个维度定义，数值待补：

1. 核心资源倾向（俸禄/摸鱼值/心力/上官好感的产出消耗修正）
2. 玩法风格（主动操作型 vs 稳定挂机型）
3. 专属随机事件池（埋梗主战场）
4. 成长曲线（前期快/后期发力/波动型）
5. 专属功法·法宝

### 3.5 职级天梯（对应真实职务序列）

```
帮闲(助理) → 书吏(专员) → 资深书吏(资深专员) → 管事(经理)
→ 副主事(副经理) → 高级副主事(高级副经理) → 知事(高级经理)
→ 少监(副总监) → 监正(总监) → 入编仙朝(最终目标，见 §6)
```

- 每级晋升 = 一次境界突破（演出用 B 风格水墨卷轴）。
- **主卡关墙**：知事 → 少监（对应现实晋升最难的一道坎）。
- **编外天花板**：编外玩家常规晋升止于知事级顶格；少监及以上在设定上只由"外派仙吏"（有编制者）出任——这是 §6 仙籍大饼机制的一部分。

## 4. NPC 图鉴

### 4.1 堂上诸公（领导层）

- 不给具体形象、不做成笑点。只以全局"天象事件"存在：
  "堂上风云变幻，各房考成从严"／"局座闭关，本月画饼暂停"。
- 保持敬畏感与神秘感；后续版本可再深化。

### 4.2 机巧阁四人组（主线剧情主舞台）

| 原型来源 | 游戏人设 | 角色功能 |
|---|---|---|
| 不懂技术的总监 | 监正「空谈真人」 | Boss 型压力源：发布离谱需求（"给传音玉简加已读回音，但要无声"） |
| 爱早退的副总监 | 少监「遁尘子」 | 亦师亦友：平时"遁走中"找不到人，危机时刻登场拿主意 |
| 博士经理（外派、收入不高、动机成谜） | 主事「烛影先生」 | 导师型 + 轻量支线（见 §6.6），答案永远留白 |
| 人好但不懂技术的资深专员 | 资深书吏「和事佬」 | 氛围组：活推给博士但真心感激，负责搞笑与温情 |

### 4.3 部门 NPC 与事件速记（细节已确认）

- **签押房**：小团体包装为「乡音会」——本地杂役多操"南洋土话"，外派仙吏只讲官话，语言不通、派系自现。组队 buff 包装："南洋土话咬耳朵"（老乡组队：协作任务效率+，但被上官撞见会扣好感）。摸鱼成风却常被"天降差事"强派任务；外派 NPC 准点下班 vs 本地 NPC 被动加班的对照。
- **户房**：只看结果的 Boss 型上官。「大限风暴」三级节奏：**每月快报（小风暴）→ 一年两次预算（大风暴）→ 年底决算（超级风暴）**，风暴期全员产出强制拉满+上官狂暴。日常活计事件：写报告、报销审核、替上官写材料（三种小玩法）。NPC 流失率全衙门最高，"送别宴"高频触发。
- **机巧阁**：日常 = 修缮法器（电脑坏了随叫随到）、牵线甲乙方（各房要造机关时的中间人）、守阵护院（设备与网络安全）。专属讽刺系统**「留痕两仪」**：监正颁"留痕令"——诸事须传讯转发、会议纪要、甘特图，百无一用但必汇成材料；少监秘传"知道越少责任越小"心法——邮件别转我、删了就与你无责。玩家在两仪间的站队影响好感与"案牍值"走向，是全游戏最有共鸣的梗点。
- **刑名房**（Phase 2）：合规堂 = 研究天条仙律、解读政策对局务的影响（风险减免 buff，事件"解读天条"）；审计堂 = 离任审计、汇整案卷（事件"查办同僚账目"，查出问题记功）。
- **广闻司**（Phase 2）：香局主业部门、出海最多；「远航四海」=长期离线模式（出海期间离线收益加成，归航结算事件）。
- **漕运司**：豪爽老漕头（给资源不眨眼）vs 精明仓吏（抠门但帮你省损耗）。
- **吏房**：冷面判官，问什么都不答。
- **察案院**：预告式巡查组织者，"检查永远在你打扫完之后来"。
- **制香坊**：只有两位高人，紧闭坊门，袅袅香烟——没人知道里面在炼什么（彩蛋部门）。

## 5. 核心循环与资源系统

### 5.1 四条基础资源线（双资源拉扯为核心乐趣）

| 资源 | 产出 | 消耗 | 作用 |
|---|---|---|---|
| 俸禄（灵石） | 工位修炼（挂机主产出）、任务结算 | 升级功法/法宝、送礼、转生折损 | 通用货币与成长主轴 |
| 摸鱼值 | 摸鱼行动（主动小玩法） | 转化为心力恢复 | 对抗倦怠的节奏阀门 |
| 心力 | 摸鱼/休沐恢复 | 工作持续消耗；归零触发"职业倦怠"（产出大降） | 逼玩家在"卷"与"摸"之间做抉择 |
| 上官好感 | 升堂议事、响应差事、表面功夫 | 摸鱼被抓、顶撞 | 晋升修正、免灾、画饼频率 |

后期新增隐藏资源：**通透值**（觉醒后解锁，见 §6.4）。

### 5.2 日常结构

- **点卯签到**：每日首登，迟到扣全勤。
- **离线收益**：在线产出的 50~70%，封顶 12~24 小时；首登弹「昨夜衙门记事」卷轴摘要。
- **燃灯值守（加班开关）**：玩家主动开启，产出×2、次日心力上限减半。
- **随机事件**：上官巡视（摸鱼时触发，考验一键切换假装修炼）、同僚甩锅、强制团建、考成盲盒等。
- **每旬考成**：小结算，评分影响俸禄与好感。

### 5.3 节奏目标

- 第一幕（1~7 天）解锁期：系统逐个解锁，爽点密集，留存关键。
- 第二幕（8~21 天）拉扯期：多资源互相制约，随机事件密度拉满，出现卡关墙。
- 第三幕（22~30 天）转折期：幻灭值注满，岔路事件触发（见 §6）。
- 具体数值公式：**占位**，进入数值调参阶段后填充（目标是每日主动操作约 15 分钟）。

## 6. 主线流程：仙籍大饼与多分支长线

### 6.1 表面目标：仙籍进度条

前中期不剧透。上官按套路画饼："好好干，下次仙籍遴选优先推荐你。"
玩家面前有一条仙籍进度条（考成+资历+好感），讽刺藏在数学里：

- 门槛永远比成长快半步（芝诺龟）：你到 99，门槛变 120；达标后改规则——"本届加试悟性，需堂上诸公亲授"（堂上诸公从不现身）。
- 接近门槛必触发："本届名额缩减"／"编制冻结，静候天庭谕旨"。

### 6.2 真相系统：旧账册

全地图散落收集品「旧账册」，记录历任编外杂役的命运（短文案，拼起来即真相）：

> "庚辰年入衙，考成连年上上。丙戌年，问仙籍，上官曰'再等一届'。己丑年，辞。"

环境叙事代替旁白。账册最后一页是烛影先生十年前写的——与他的支线联动。

### 6.3 岔路事件：「仙籍冻结谕旨」（必然发生）

天庭下旨仙籍遴选无限期冻结 + 老杂役告别宴，饼官方性碎裂。
**触发机制：幻灭值量表（双轨合一）**

- 进度来源（肝帝快车道）：收集旧账册、撞仙籍墙、参加告别宴、目睹画饼——大额充能。
- 时间来源（挂机党保底）：每现实日自动涨格，**约 30 天恰好注满**。
- UI 只显示模糊的"心事"图标，不显示数字。文案基调："你心里的弦，一根一根地断了。"

### 6.4 分支 A：留下来（觉醒留任）

不删档不重置，叠加新玩法层：

- **通透值**解锁：不再信饼，画饼事件由压力源变笑点来源，每次画饼 +通透值。
- **带徒弟系统**：新编外杂役 NPC 归你带，徒弟产出抽成——放置自动化层，包装成"老油条带新人"。
- **编外登顶线**：爬到编外职级顶格（知事级），称号"十年陈酿"+全收集线。

### 6.5 分支 B：离开（跳槽转生 / 自立衙门）

**B1 跳槽 = 转生系统**：改换门庭至竞争对手（云雾香局／凌霄香号等，各自规则不同），
保留「宦海感悟」，重置职级与俸禄。转生收益三维合成：

```
宦海感悟 = 属性转化（肝帝路线） + 遣散补偿（挂机党路线，按服役天数结算，含"N+1"梗）
        + 阅历集藏（收集党路线：账册/图鉴/成就折算）
```

三条路各占约三分之一量级，任何一类玩家都不被系统抛弃。

**B2 自立衙门 = 管理模式**：攒够盘缠自开衙署，雇佣 NPC 挂机产出，身份反转当上官——
"给不给手下画仙籍的饼，由你决定"（道德选择 + 通关后长线内容）。

**分支串联**：岔路存档点（「功过分册·存照」）可随时回档换路；一个存档可走完三种人生。

### 6.6 烛影先生支线（轻量、留白）

三次偶遇式短事件，无解谜系统：

1. 中期·深夜机关阁："这盏灯修好了，明早大家传音就不断了。"
2. 后期·你拿旧账册给他看，他笑而不答："帮我带杯茶吧，谢了。"
3. 通关后·桌上多了一本手抄《机关图录》，扉页："**留着的东西，不一定都是为了等一个答案。**"

他为何留下——永远不给结论。

### 6.7 觉醒永久性

- 觉醒状态跨转生保留；新东家的画饼对觉醒者加通透值。
- 集藏（账册/图鉴/成就）跨转生保留，只重置职级与俸禄。

## 7. 排行榜与社交

### 7.1 Phase 1（朋友局，仅排行榜）

- **NPC 同僚填榜**：20~30 个成长曲线精心设计的 NPC（名字、性格、卷度各异），榜单永远热闹；朋友实际是在与 NPC 竞速中互相较劲。
- **多维榜单**：
  - 周榜（每周一重置）：本周俸禄、本周摸鱼时长、考成评分——避免固化。
  - 历史榜（永久）：最高职级、累计资产、成就数——转生玩家不掉价（比累计/历史最高，不比当前进度）。
  - 整活榜：摸鱼仙人、背锅次数、开会时长、"编外服役时长"、称号"十二年陈酿杂役"。
  - 结局图鉴收集度上榜："你只走了两条路？"
- **反作弊前置**：服务端权威存档，离线收益由服务器在登录时结算，杜绝改本地存档/系统时间。

### 7.2 Phase 2（DLC，待游戏主体完成后）

互坑甩锅类异步互动：甩锅任务、内卷冲击、摸鱼搭子结盟等。
数据模型第一天即预留 `interactions` 结构（对某玩家施加定时生效的 buff/debuff），届时加接口不动核心。

## 8. 美术风格与 UI 规范

### 8.1 风格

- **主风格（A）**：国潮扁平插画，幽默向（参考《最强蜗牛》《动物餐厅》气质）——UI 主体、NPC 立绘、图标。
- **点缀（B）**：水墨国风——仅用于晋升/渡劫/岔路等重大时刻的全屏卷轴过场，反差即爽点。
- 配色：青绿 `#2A9D8F` · 朱红 `#E76F51` · 米白 `#F7F1E3` · 墨黑 `#264653` · 金箔 `#E9C46A`（仅高光时刻）。

### 8.2 美术管线（单人开发原则：少画、复用、AI 兜底）

1. 角色不做动画：立绘 + 2~3 表情差分，事件表现靠立绘切换 + 文字气泡。
2. AI 生成 + 统一提示词模板保证一致性。
3. 图标用开源素材库（IconPark / Game-icons.net）+ 统一描边配色滤镜。
4. 字体：标题用免费商用书法体，正文思源黑体，数字用等宽大字号。

### 8.3 UI 布局（PC 三栏式）

```
┌────────────────────────────────────────────────┐
│ 顶栏：官职名号 · 资源总览 · 心力条             │
├──────────┬──────────────────────┬───────────────┤
│ 左栏 22% │ 中央 52%             │ 右栏 26%      │
│ 立绘/境界│ 衙门工位主场景       │ 衙门情报流    │
│ 属性面板 │ 产出显示/行动按钮    │ (事件日志)    │
├──────────┴──────────────────────┴───────────────┤
│ 底部 Tab：考成 | 同僚榜 | 库房 | 功法 | 设置    │
└────────────────────────────────────────────────┘
```

- 主场景随职级更换（杂役房→书吏阁→主事堂…），"升官看得见"。
- 底部 Tab 为红头文件式标签，切页盖章动画。
- 交互要点：收菜数字瀑布（做得"脆"）、摸鱼按钮按住切换躺平立绘+上官接近度警报、离线收益弹「昨夜衙门记事」卷轴。
- 手机自适应：单列 + 底部 Tab，情报流折叠为抽屉。
- 性能预算：纯 DOM/CSS 实现，首屏资源 ≤10MB，WebP + 懒加载。

## 9. 技术架构

### 9.1 总体

- **前端**：TypeScript + React，纯 DOM 渲染（放置游戏无重度渲染需求）；PC 浏览器直玩，可选 Electron 壳；手机浏览器自适应。
- **后端**：轻量单体服务（Node.js/Go 待定，倾向 Node 与前端同栈）+ 关系型数据库（SQLite 起步，预留迁移 PostgreSQL）。
- **通信**：REST + 短轮询即可（Phase 1 无实时需求）。
- **部署**：一台低配 VPS 承载朋友局；网游化仅需升配置。

### 9.2 服务端权威原则（排行榜公平性地基）

- 存档存服务端，客户端只做展示与输入。
- **离线收益由服务器在登录时结算**（依据上次登出时间戳），不信任客户端上报。
- 所有产出计算在服务端可重放验证。

### 9.3 数据模型预留（为网游化与 DLC 铺路）

- `accounts`（账号）、`saves`（权威存档快照）、`offline_settlements`（离线结算流水）。
- `interactions`（预留：异步互动的 buff/debuff 投递队列，DLC 用）。
- `leaderboards` 按（维度 × 赛季）存储，周榜赛季每周一滚动。
- 玩家行为日志表（为后续平衡调参留数据）。
